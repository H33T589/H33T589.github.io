Instructions

🎯 How to Use:

  • Click on the canvas to place sound sources
  • Drag existing sources to reposition them
  • Blue circle (center) is the listener
  • Use controls to adjust audio parameters
  • Wear headphones for best spatial experience

🔊 What You'll Experience:

  • Audio pans left/right as sources move
  • Volume decreases with distance
  • Real-time 3D spatial positioning
  • Visual sound wave representation

🛠️ Built with Web Audio API

This spatial audio engine uses the browser's Web Audio API with PannerNode for real-time 3D sound positioning. Move the sound sources around the canvas to hear the audio change in position and intensity!
